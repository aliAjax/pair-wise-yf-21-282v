# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

做一个给手工地毯修复工作室使用的纹样与修复档案前端项目，可以记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面需要有纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 技术栈

React + Vite + TypeScript

## 功能

- 档案录入与按产地筛选：记录产地、年代、结密度、材质、染色类型、破损区域、破损程度与补线色卡需求
- 修复排期：未完工地毯按「破损程度重 → 年代早」排先修顺序，自动分配给当日还有件数余量的修复师；全员排满后进入等待区并给出等待原因。调整修复师当日件数或推进工序后自动重排
- 领料与色卡：领料时余量够多少领多少，库存不会扣成负数；缺口保留并提示待补货，补货后再次领取即可补齐
- 工作台摘要与地毯详情：实时显示各修复师当日件数、等待区队列、色卡余量、每件地毯的进度 / 等待原因 / 缺料情况，支持导出 CSV

## 本地运行

```bash
npm install
npm run dev
```
